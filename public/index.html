Your own agents

Anything that can make an HTTP call can register itself, report runs, stream a live timeline, ask for approval and pick up instructions. Use this token, never your password.

Endpoints: POST /api/agents/register, POST /api/ingest (tasks and finished runs), POST /api/runs then /api/runs/:id/events and /api/runs/:id/finish (a live run), POST /api/approvals/request (ask before a risky action), GET /api/inbox and POST /api/inbox/:id/ack (instructions). Live updates for your own tools: GET /api/stream. The examples/ folder has a shell script, a Claude Code routine prompt and an MCP server for Cowork.
