Getting started

  1. Log in once. Open the browser screen, sign in to ChatGPT, Claude and Grok in the tabs you see. The session is kept on the persistent disk.
  2. Sync. Press Sync all. Each platform card gets a live screenshot, its session state, and any tasks the app exposes.
  3. Register the rest. Add agents that run elsewhere (Cowork, Muse, your own bots) with Add agent, and have them report runs to POST /api/ingest.
